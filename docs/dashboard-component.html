BandHub Frontend

Documentação do DashboardComponent

Guia visual para entender a tela principal autenticada do BandHub: feed musical, posts mockados, navegação lateral, tendências e sugestões de bandas em um componente Angular standalone.

Selector app-dashboard
Tipo Standalone component
Rota atual path: ''
Dados Posts estáticos para prototipação

Propósito

O DashboardComponent representa o feed principal do usuário autenticado. Ele simula uma rede social musical com posts, imagens, contadores de curtidas e comentários.

Arquivos

  • dashboard.component.ts: metadados e dados mockados.
  • dashboard.component.html: estrutura visual do feed.
  • dashboard.component.css: estilos da tela.

Dependência

Importa CommonModule para liberar diretivas comuns do Angular, como *ngFor e *ngIf, usadas no template.

Metadados Angular

import { Component } from '@angular/core';
import { CommonModule } from '@angular/common';

@Component({
  selector: 'app-dashboard',
  standalone: true,
  imports: [CommonModule],
  templateUrl: './dashboard.component.html',
  styleUrls: ['./dashboard.component.css']
})
export class DashboardComponent {
  posts = [...]
}

Como ler esse bloco

  • selector define a tag usada para renderizar o componente.
  • standalone: true permite usar o componente sem declarar em um NgModule.
  • imports registra recursos necessários ao template.
  • templateUrl e styleUrls mantêm HTML e CSS em arquivos separados.

Estrutura de um post

id Identificador numérico usado para diferenciar cada publicação.
author Nome da banda, músico, festival ou perfil que publicou o conteúdo.
avatar URL da imagem exibida no cabeçalho do card do post.
time Texto amigável com o tempo desde a publicação.
content Mensagem principal exibida no corpo do post.
image? Imagem opcional do post. Quando não existe, o template não renderiza a tag de imagem.
likes Total de curtidas exibido no rodapé do card.
comments Total de comentários exibido no rodapé do card.

Fluxo do template

1

Sidebar esquerda

Exibe marca BandHub, menu de navegação e botão para criar post.

2

Criação de post

Mostra avatar do usuário, input e botão de postagem. Ainda é visual, sem integração com formulário.

3

Feed

Usa *ngFor para criar um card para cada item do array posts.

4

Sidebar direita

Apresenta assuntos em alta e sugestões de bandas para seguir.

Diretivas no HTML

<div class="post-card" *ngFor="let post of posts">
  ...
  <img
    *ngIf="post.image"
    [src]="post.image"
    alt="Post Imagem"
    class="post-image"
  >
</div>

Comportamento importante

O *ngFor percorre o array inteiro e cria um card por post. O *ngIf evita que posts sem imagem renderizem uma imagem vazia, mantendo o layout limpo.

No futuro, o array posts deve ser substituído por dados vindos de um serviço Angular integrado à API.
